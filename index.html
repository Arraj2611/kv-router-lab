How the model works. Prompts are split into 16-token blocks. A block counts as cached only if every block before it is cached too, the way vLLM's chained block hashes work. Each replica runs prefill one request at a time and evicts least-recently-used blocks, oldest leaves first. Time to first token is queueing delay plus prefill of the uncached part; decoding is not modelled.

What it leaves out. No batching, so queues grow faster than on a real engine near saturation: trust the ranking of strategies more than the absolute seconds. No cache offload tier, no replica failures, and the approximate router never forgets what it routed.
